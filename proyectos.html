  1. Septiembre 2026 – en curso

    Portfolio

    Proyecto personal

    Este mismo sitio web: un portfolio personal multipágina (Sobre mí, Proyectos, Experiencia, Habilidades, Formación y Contacto) construido con HTML, CSS y JavaScript puro, sin frameworks ni paso de build, y desplegado en GitHub Pages. Lo hice para dar contexto al currículum y enseñar con más detalle lo que sé hacer.

    • Sitio de once páginas en HTML, CSS y JavaScript puro, sin frameworks ni bundler.
    • Bilingüe (español e inglés) con un diccionario i18n propio en JavaScript. El idioma y el tema elegidos se guardan entre visitas con localStorage.
    • Tema claro y oscuro que respeta la preferencia del sistema (prefers-color-scheme).
    • Componentes interactivos hechos a mano: carruseles con arrastre táctil, cronologías con buscador y ordenación, y menú responsive.
    • Animaciones de aparición al hacer scroll con IntersectionObserver.
    • Atención a la accesibilidad (enlace para saltar al contenido, roles ARIA, aria-expanded) y al SEO (meta description, Open Graph, Twitter Card, canonical) en cada página.
    • Entorno de desarrollo local con Docker y browser-sync con recarga automática.

  2. Febrero 2026 – Agosto 2026

    Tokimori

    Proyecto personal · Full-stack · Arquitectura de microservicios

    Aplicación web full-stack para gestionar una colección personal de elementos con seguimiento de tiempo, notas en Markdown, checklists y un lienzo visual por elemento. Construida sobre una arquitectura de 6 microservicios en Node.js/TypeScript tras un API Gateway (nginx), con frontend en React 19 y despliegue completo con Docker Compose.

    • Diseñé una arquitectura de 6 microservicios (auth, items, colección, notas, objetivos/canvas, sesiones) en Node.js + Express 5 + TypeScript, cada uno con su responsabilidad y base de datos MySQL compartida (8 tablas).
    • Implementé un API Gateway con nginx como único punto de entrada público, que enruta por path al frontend y a cada servicio. Los servicios internos no son accesibles desde fuera de la red Docker.
    • Autenticación con JWT (tokens de 7 días) sobre cookies secure, hashing con bcrypt, y endurecimiento con helmet, rate limiting y CORS configurable.
    • Desarrollé un canvas visual por elemento con la HTML5 Canvas API sin librerías: dibujo libre, formas, imágenes y texto, con arrastre, redimensionado y rotación, historial de deshacer/rehacer y control de capas (z-index).
    • Frontend en React 19 + Vite 7 + React Router 7 + TypeScript, con React Compiler, CSS Modules, sistema de i18n propio (es/en) e interfaz con tema claro/oscuro/automático y color de acento configurable.
    • Creé utilidades a medida: drag & drop con animaciones FLIP (hook useFlipList), render de Markdown propio, temporizador flotante persistente entre páginas y notificaciones del navegador.
    • Panel de estadísticas globales (horas totales, racha de días, gráfico de 7 días), sistema de logros desbloqueables, panel de administración y cuenta demo.
    • Testing con Vitest + Testing Library (frontend) y Jest + Supertest (backend). Contenerización completa con Docker Compose, separando la configuración de producción (frontend compilado servido por nginx) y un override de desarrollo (Vite hot-reload).

  3. Abril 2025 – Junio 2025

    PuppyClicker

    Proyecto personal · Full-stack · Juego de navegador

    Juego de navegador tipo clicker protagonizado por perros. Cada click suma puntos, y con ellos se compran razas que producen puntos de forma automática y mejoras que multiplican esa producción. Aplicación full-stack con frontend en React 19 y TypeScript, API REST en Node.js/Express sobre MySQL y despliegue con Docker Compose.

    • 9 razas con precio creciente (+15 % por unidad comprada) y 60 mejoras que duplican los puntos por click o la producción de cada raza.
    • API REST en Node.js + Express 5 + TypeScript con 10 endpoints sobre MySQL 8, con un modelo relacional de 7 tablas diseñado en MySQL Workbench.
    • Autenticación con JWT y contraseñas con bcrypt; precios, multiplicadores y producción se calculan en el servidor, y las compras van en transacciones con bloqueo de fila.
    • Frontend en React 19 + TypeScript + Vite + React Router, con fotos aleatorias de la API pública dog.ceo, animaciones de click y curiosidades sobre perros que rotan cada 10 segundos.
    • Docker Compose con frontend, backend y MySQL; el esquema y los datos del juego se cargan solos en el primer arranque.
    • Desarrollo por ramas de funcionalidad integradas mediante 8 pull requests.

  4. Diciembre 2024 – Enero 2026

    Auscultify

    Trabajo de Fin de Grado (9,4/10) · Full-stack · Microservicios · Sistemas de recomendación

    Mi Trabajo de Fin de Grado: una aplicación web para que estudiantes de medicina entrenen la auscultación con audios reales, en sesiones de 10 preguntas tipo test. Construida con 9 microservicios en Node.js/TypeScript y Python/Flask, frontend en React 19 y despliegue con Docker Compose. Lo defendí en febrero de 2026 y obtuvo un 9,4/10.

    • Arquitectura de 9 microservicios: 8 en Node.js + Express + TypeScript para la lógica de negocio y 1 en Python + Flask para los algoritmos, con MySQL 8 y Docker Compose.
    • Sistema de recomendación con 11 algoritmos para elegir las preguntas de cada sesión, desde métodos base hasta filtrado colaborativo basado en usuarios y en ítems con correlación de Pearson.
    • Frontend en React 19 + TypeScript + Vite con estadísticas individuales y gráficas en Chart.js, racha de días y comparativa con los usuarios que sigues.
    • Panel de administración para subir audios y gestionar categorías y preguntas, sincronizado con la base de datos y con la carpeta de audios del repositorio.
    • Análisis y diseño completos (27 requisitos funcionales, casos de uso, modelo de datos y prototipos en Figma), dos memorias en LaTeX descargables y defensa oral ante tribunal.
